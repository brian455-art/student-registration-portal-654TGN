# Student Registration Portal

A responsive student registration portal built using HTML, CSS and JavaScript.

## About the Project

The Student Registration Portal is a beginner-friendly web development project designed to demonstrate how students can register and how their information can be displayed and managed through a web interface.

## Features

- Student registration form
- Input validation
- Student records table
- Search registered students
- Delete student records
- Responsive user interface
- Browser local storage for saving records

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## How to Run the Project

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. View the application in your browser.
